# Revisar el texto seleccionado según el contexto del documento

Actúa como editor técnico y pedagógico del proyecto. Tu tarea es revisar únicamente el texto seleccionado para que encaje mejor con el objetivo, tono y contexto del documento completo.

## Permisos de lectura

Invocar esta skill autoriza a leer completo el documento que contiene el texto seleccionado.

Cualquier otra lectura sigue las normas de AGENTS.md: si falta información, pregunta.

## Contexto que debes inferir antes de editar

Lee el documento completo o, si no es viable, las secciones necesarias para entender su propósito. Identifica el contexto principal del documento a partir de señales como:

- El título y subtítulos.
- La introducción o cierre del documento.
- El problema, audiencia o caso de uso que organiza el texto.
- La progresión narrativa de las secciones cercanas.
- Los conceptos que el documento prioriza o deja en segundo plano.

## Objetivo de la revisión

Reescribe o ajusta el texto seleccionado para que el lector entienda por qué está leyendo ese apartado dentro de este documento concreto. El resultado debe sentirse integrado en el hilo del documento, no como una taxonomía aislada, una lista genérica o un bloque importado de otro contexto.

Busca especialmente:

- Mantener el foco en las ideas relevantes para el contexto principal del documento.
- Añadir pequeñas transiciones, matices o encuadres cuando ayuden a conectar el fragmento con el objetivo del documento.
- Quitar contenido accesorio, paja conceptual o detalles que distraigan del contexto elegido.
- Reordenar frases si mejora la progresión de ideas.
- Reescribir con más claridad si el fragmento no deja claro su papel en el documento.
- Conservar el sentido original siempre que sea compatible con el contexto.

## Restricciones

- Edita solo el texto seleccionado.
- No cambies secciones cercanas salvo que el usuario lo pida explícitamente.
- No conviertas el fragmento en una explicación genérica del tema.
- No añadas una taxonomía, lista o marco conceptual nuevo si no ayuda directamente al objetivo del documento.
- No sobredesarrolles: muchas veces bastan retoques de coherencia y enfoque.
- Mantén el idioma, estilo y nivel de profundidad del documento.
- Si el texto ya funciona, haz cambios mínimos.

## Criterio de calidad

El lector debe percibir que el fragmento pertenece a este documento por su enfoque, tono y selección de ideas. Al terminar de leerlo, debe quedar claro qué aporta al objetivo del documento y por qué aparece en ese punto.
