# datos.gob.es

Noticia: <https://administracionelectronica.gob.es/pae_Home/pae_Actualidad/pae_Noticias/2026/Marzo/noticia-2026-03-19-API-Administraciones-Publicas.html>

El artículo parte de la [regulación europea de Datos de Alto Valor (HVD)](https://datos.gob.es/es/noticias/europa-define-los-conjuntos-de-datos-de-alto-valor-que-el-sector-publico-tendra-que-abrir), establecida por el Reglamento de Ejecución (UE) 2023/138, que desde el 9 de junio de 2024 obliga a los organismos públicos de toda la UE a publicar de forma gratuita, en formatos legibles por máquina y accesibles mediante API, los conjuntos de datos de seis categorías: geoespaciales, observación de la Tierra, medio ambiente, estadística, información empresarial y movilidad. Los Estados miembros deben además [reportar cada dos años](https://datos.gob.es/es/blog/avances-en-los-datos-de-alto-valor-en-espana) a la Comisión Europea su grado de cumplimiento, incluyendo enlaces persistentes a esas API; la situación de España puede consultarse en el [Open Data Maturity Report](https://data.europa.eu/en/open-data-maturity/2025#country-profiles/country_ES).

Para ilustrar cómo se aplica este marco, el artículo repasa un inventario de API públicas españolas. El INE ofrece una [API REST](https://www.ine.es/dyngs/INEbase/listaoperaciones.htm) que expone toda la base Tempus3 en JSON sin necesidad de autenticación. AEMET expone datos meteorológicos observados y predicciones a través de una [API REST documentada con Swagger](https://opendata.aemet.es/centrodedescargas/inicio), que requiere una API key gratuita y funciona mediante un modelo de doble llamada, con un límite de 50 peticiones por minuto. El Centro Nacional de Información Geográfica publica cartografía, modelos digitales del terreno y redes hidrográficas a través de servicios que han evolucionado desde WMS/WFS hacia los estándares OGC API (Features, Maps y Processes), sirviendo los datos en GeoJSON en lugar del más pesado GML. El MITECO, por su parte, mantiene un portal basado en CKAN con tres capas de acceso —Action API, Datastore API y endpoints RDF/JSON-LD conformes con DCAT-AP y GeoDCAT-AP— para datos de calidad del aire, agua, biodiversidad, residuos y energía.

Una tabla comparativa resume protocolo, formato, autenticación y límites de uso de estas cuatro API, mostrando distintos niveles de madurez: mientras INE y AEMET disponen de interfaces consolidadas y bien documentadas, otros organismos siguen apoyándose en portales CKAN o servicios OGC más tradicionales.

El artículo destaca que la disponibilidad de estas API no es solo una cuestión de comodidad técnica, sino que habilita tres capacidades clave para los profesionales de datos: automatización de pipelines de ingesta sin intervención manual, reproducibilidad gracias a URL que actúan como referencias estáticas y auditables, e interoperabilidad al apoyarse en estándares abiertos como REST, OGC API o DCAT-AP que permiten cruzar fuentes heterogéneas.

En una frase: la obligación europea de abrir los Datos de Alto Valor está impulsando en España un ecosistema de API públicas —desde el INE hasta el MITECO— con distintos grados de madurez, pero ya plenamente operativo para su integración en arquitecturas de datos y analítica.
