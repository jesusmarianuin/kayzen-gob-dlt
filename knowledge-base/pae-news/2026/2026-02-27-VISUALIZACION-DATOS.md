# datos.gob.es

Noticia: <https://administracionelectronica.gob.es/pae_Home/pae_Actualidad/pae_Noticias/2026/Febrero/noticia-2026-02-27-Visualizar-datos-publicos-que-herramientas-existen-y-para-que-sirven.html>

datos.gob.es repasa el ecosistema actual de herramientas de [visualización de datos](https://datos.gob.es/es/blog/las-herramientas-de-visualizacion-de-datos-mas-populares), que se ha democratizado gracias a opciones gratuitas o de código abierto: ya no hace falta un perfil especializado para representar gráficamente información pública.

El artículo las agrupa por nivel de uso: herramientas sencillas para empezar (Excel, Google Sheets, Datawrapper, RAWGraphs, Canva); herramientas de análisis y exploración (R, ggplot2, Python con Matplotlib/Plotly, Apache Superset); herramientas para visualización interactiva y web (D3.js, Vega/Vega-Lite, Observable, Three.js/WebGL); y herramientas de cartografía y datos geoespaciales (QGIS, ArcGIS, Mapbox, Leaflet). La selección se basa en la encuesta anual de la [Data Visualization Society](https://www.datavisualizationsociety.org/soti-report-2024), priorizando siempre acceso libre o gratuito y utilidad para datos públicos.

El texto incluye también un [ejercicio práctico](https://datos.gob.es/es/conocimiento/disena-y-visualiza-con-d3js-datos-de-siniestralidad-en-carretera) con D3.js sobre datos de siniestralidad en carretera, y enlaza a otras entradas del propio blog sobre [cómo elegir el gráfico correcto](https://datos.gob.es/es/blog/como-elegir-el-grafico-correcto-para-visualizar-datos-abiertos) o [diseñar con integridad](https://datos.gob.es/es/blog/disenar-visualizaciones-de-datos-con-integridad-mas-alla-de-los-graficos-bonitos).

En una frase: guía práctica de datos.gob.es con las herramientas de visualización de datos más usadas hoy, agrupadas por nivel (iniciación, análisis, interactivas y geoespaciales), pensada para quien trabaja con datos abiertos.
